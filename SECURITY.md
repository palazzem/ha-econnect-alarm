# Security Policy

## Supported versions

Security fixes go into the latest release. Update to it before you report a vulnerability, and check that it is still there.

## Reporting a vulnerability

Report it privately through [GitHub's vulnerability reporting](https://github.com/palazzem/ha-econnect-alarm/security/advisories/new). Do not open a public issue or pull request, and do not discuss it on Discord.

Include:

- The integration and Home Assistant versions, and whether your system is Elmo e-Connect or IESS Metronet.
- What an attacker can do, and the steps to reproduce it.
- The relevant code or log lines.

Never include your username, password, alarm codes, session tokens, or data from your alarm panel. Replace them with invented values.

The conversation, the fix, and the advisory that announces it all happen in the private report.
